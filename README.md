# Vibe Finder

> Find your vibe.

**Vibe Finder** это интерактивный сайт, который определяет настроение пользователя по ответам на несколько вопросов и подбирает подходящую атмосферу.

🌐 **https://vibefinder.tech**

## Как это работает

1. Пользователь отвечает на несколько вопросов.
2. Система определяет подходящий вайб.
3. Открывается соответствующая атмосфера.
4. Внутри вайба доступны музыка и мини-игра.

## Вайбы

Каждый вайб имеет своё оформление, атмосферу и интерактивные элементы.

### 🎮 Игры

В проекте есть несколько мини-игр:

- **Retro Arcade**  
  Аркадная игра.

- **Night Walk**  
  Интерактивная прогулка по ночному городу.

- **Cozy Room**  
  Создание уютной комнаты.

- **Paint by Numbers**  
  Раскрашивание изображения по номерам.


Также добавлены звуки интерфейса и атмосферные звуковые переходы.
